Opala SS 73 — versão PWA

Arquivos:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Como usar no iPhone:
1. Publique estes arquivos num site simples, como GitHub Pages, Netlify ou Vercel.
2. Abra o link no Safari.
3. Toque em Compartilhar.
4. Escolha "Adicionar à Tela de Início".

Observação:
No iPhone, PWA não instala bem a partir de arquivo local. Ele precisa abrir por URL.
